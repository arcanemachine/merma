Code

Tab: next · Enter: select · Esc: cancel
Viewing
Wheel or pinchZoom in or out
DragMove diagram
Double-click empty spaceFit to window
Editing flowcharts
ClickSelect node, edge or subgraph
Right-click or long-pressOpen menu
Double-click a nodeEdit node
Double-click an edgeEdit label
Double-click a subgraph or the titleEdit title
Keys
Keyboard shortcuts are case-insensitive.
+ or -Zoom in or out
0Zoom to actual size
FFit to window, or center the selection
/Find in diagram
`Go to code panel, or hide it
M or Shift+F10Open menu
EscCancel or deselect
Ctrl+Z⌘+ZUndo
Ctrl+Shift+Z or Ctrl+Y⌘+Shift+ZRedo
Keys with nothing selected
Arrows, with Ctrl⌥ or ShiftMove diagram (further, or less)
EnterSelect last item, or middle node
NAdd node
Keys with something selected
Arrows on a node or subgraphGo in, select edge leaving that way, or select next item
Arrows on an edgeFollow edge, or step to edge beside it
The opposite arrowGo back
Ctrl⌥+ArrowsSkip edge, or select next item that way
Space on an edgeWalk other end's edges
OSelect enclosing subgraph
I on a subgraphSelect item inside
Up on a node in the top rowSelect title
N on a nodeAdd connected node
N on a subgraphAdd node
C on a node or subgraphConnect to…
R on an edgeReverse edge
Enter or F2 on a nodeEdit node
Enter or F2 on an edgeEdit label
Enter or F2 on a subgraph or the titleEdit title
1–9, 0 on a nodeEdit shape
1–9, 0 on an edgeEdit arrow type
Delete or BackspaceDelete node or edge
Arrows, then Enter, in Connect to…Pick node or subgraph to connect to
Down in a node's labelEdit shape
