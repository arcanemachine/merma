Viewing

  • Scroll zooms at the cursor; drag moves the diagram.
  • Double-click empty space, or Reset view, fits it to the window.
  • The page follows the file: save it anywhere and the diagram updates within a second.

Editing (flowcharts only)

  • Click a node to select it. Right-click it (or long-press) for its menu: add a connected node, connect it to another, edit its label, or delete it.
  • Click an edge (its line or its label) to select it; right-click it to edit its label, reverse it, change its arrow or delete it. Double-click it to edit its label.
  • Right-click empty space to add a node (inside a subgraph, it goes in that subgraph).
  • N adds a node: connected to the selected one, if any. Enter or F2 edits the selected node's or edge's label. Delete or Backspace deletes the selected node or edge.
  • Double-click a node or an edge to edit its label: Enter saves, Shift+Enter starts a new line, Esc cancels.
  • Ctrl+Z (⌘+Z on a Mac) undoes this page's last edit; Ctrl+Shift+Z (⌘+Shift+Z) or Ctrl+Y redoes it.
  • Edits are written into the file as small text changes; nothing else in it is touched.
