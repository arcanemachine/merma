Viewing

  • Scroll zooms at the cursor; drag moves the diagram.
  • Double-click empty space, or Reset view, fits it to the window.
  • The page follows the file: save it anywhere and the diagram updates within a second.

Editing (flowcharts only)

  • Click a node for its menu: add a connected node, connect it to another, or rename it.
  • Double-click a node to rename it: Enter saves, Esc cancels.
  • Ctrl+Z undoes this page's last edit.
  • Edits are written into the file as small text changes; nothing else in it is touched.
